# M1 static userspace foundation

This is the M1 snapshot; [M2](m2.md) adds floating point, processes and PTY support.

M1 extends the existing reference interpreter and adds a persistent Linux state
object plus `trames-vfs`. It executes selected static BusyBox programs compiled
from unchanged upstream BusyBox and musl sources. There are no filename-based
behaviors, native guest library interception, dynamically generated host code,
third-party Rust dependencies, or guest-to-host syscall forwarding.

## CPU and memory

The new integer groups cover logical immediates, SBFM/BFM/UBFM, EXTR, extended
register addition/subtraction, CSEL and related forms, CCMP/CCMN, TBZ/TBNZ,
multiply/add/subtract including long and high products, signed/unsigned division,
variable shifts/rotates, RBIT/REV/CLZ/CLS, and ADC/SBC. Unallocated widths and
encodings fault. Division by zero produces zero; signed MIN/-1 wraps, as AArch64
requires. W writes still zero-extend. TPIDR_EL0 and NZCV reads/writes are modeled.

Memory instructions now include paired, signed, unscaled, register-offset,
pre-index and post-index integer accesses, plus SIMD register loads/stores.
Full pair buffers are checked before changing registers, memory or writeback
bases. SIMD support is limited to data transfers and integer modified immediates,
DUP, INS, UMOV/SMOV and vector AND/ORR/EOR. General SIMD and scalar floating-point
arithmetic remain unsupported.

LDXR/LDAXR record address, size and memory revision. STXR/STLXR succeed only with
a matching reservation and unchanged revision, and otherwise return failure.
The reservation is cleared on a store attempt or CLREX. Ordinary writes, mapping
and protection changes invalidate it conservatively; spurious exclusive failure
is allowed architecturally. LDAR/STLR and barriers run in the single-thread
interpreter's ordered memory model. This does not establish multithread support.

DCZID_EL0 describes 64-byte guest cache-zero blocks; DC ZVA checks and zeroes
guest memory. The differential tests select QEMU cortex-a53 to match this model.
BTI and pointer-authentication HINT encodings act as base ARMv8 compatible hints;
pointer authentication and branch-target protection are not enabled guest
features. Other authentication instructions are not silently implemented.

Anonymous mappings support protection flags, MAP_FIXED replacement and
MAP_FIXED_NOREPLACE. Replacement preflights the memory limit before changing
existing bytes. brk failure returns the prior break. The break starts after ELF
load pages, before the stack mapping is added. Initial auxv now includes
AT_RANDOM backed by host `/dev/urandom`; host entropy failure rejects loading.

## Linux ABI and VFS

The Linux state owns descriptors, VFS, heap break, mapping cursor and clear-child
TID registration. Implemented syscall groups include read/write/writev,
openat/close/lseek/getdents64, mkdirat/chdir/getcwd, fstat/newfstatat/faccessat,
selected fcntl operations, ioctl ENOTTY, brk/mmap/munmap/mprotect, virtual IDs,
umask, set_tid_address, and exit/exit_group. Unsupported operations return errors;
futex WAIT with a matching value remains ENOSYS, not a fabricated completed wait.

AArch64 open flags are taken from its ABI: O_DIRECTORY=0x4000,
O_NOFOLLOW=0x8000 and O_LARGEFILE=0x20000. x86_64 constants are not reused.
Guest stat is explicitly serialized into the 128-byte AArch64 Linux layout.
Virtual timestamps, UID/GID and inode values describe the VFS, not host metadata.

The VFS stores byte paths and data in a bounded BTreeMap. Components are resolved
in order; `file/..` returns ENOTDIR. Root `..` stays at root. Directory traversal
and file access permissions are checked. Directory records use Linux dirent64
alignment and continuation cookies. The only device is `/dev/null`.

The CLI's explicit file import reads one authorized host file and installs a
copy at a virtual path. Subsequent guest operations cannot resolve host names or
modify the source file. This is an in-memory root and import API, not a general
mount table or security-scoped iOS Files adapter. Imported parents and files are
preflighted against the node and data limits.

read checks its output buffer before consuming stdin or a file position.
writev validates the entire selected buffer set before calling its sink once;
short writes are returned without retry. Descriptor close/reuse and fcntl state
persist across syscalls. Nonblocking console I/O is rejected because the current
host sink cannot promise that behavior. Embedders control stdin/stdout/stderr
through the byte-stream trait; interactive PTYs and cancellation belong to M2.
