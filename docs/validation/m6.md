The static AArch64 fixture executes unchanged under Trames and the independent
QEMU 10.0.13 oracle. It checks counters and overflow, epoll fault preflight and
one-shot consumption, fd alias lifetime and fairness, relative/absolute timers,
signal-mask restoration, local stream/datagram IPC, POSIX record-lock contention,
waiting, split ranges and deadlocks, shared-file-table thread exit and killed
fork ownership, trailing paths, and named FIFO opening,
interruption, EOF, dup/unlink and FIONBIO. QEMU does not dispatch epoll_pwait2;
the fixture permits its ENOSYS fallback under QEMU but separately requires the
Trames implementation to succeed.

FIFO inode metadata persists in the current v3 manifest; live queue contents do
not persist. A disk-reopen test checks this distinction. Rust tests also cover
captured descriptor ownership and /proc/stat's stable boot time. The syscall
audit probes every undispatched inventory number with zero arguments on both
backends, requiring -ENOSYS; that probe does not validate implemented arguments.

The real-tool harness imports the pinned Alpine 3.22.6 minirootfs and serves
unmodified Alpine-signed v3.22 main/community indexes and packages through the
virtual HTTP egress gateway. APK validates its original signatures with the
rootfs keys. Dependencies are resolved by apk, including virtual providers and
conditional Git/Python packages. No permissive signature flags are used.

The local development harness may reuse an explicitly selected disposable
store with TRAMES_M6_SKIP_INSTALL=1; that mode is labelled and does not retest
installation. CI uses a fresh store and installs all tools normally for both
reference and C++ backends. Reopening the store verifies compiled binaries,
repository contents and user data. Both final CI jobs completed this fresh-store
path; debug reuse was used only while developing the local workflow checks.

These programs exercise selected workloads. They do not establish arbitrary
software, large-project builds, Debian compatibility or physical iPad speed and
memory acceptance. [Scope and remaining ABI work](../roadmap/compatibility-m6.md).
