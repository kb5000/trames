# M1 validation record

Date: 2026-10-10. Local platform: Debian 13, x86_64. Rust 1.90.0, GCC AArch64
14.2.0, Binutils 2.44, QEMU user-mode 10.0.13, Python 3.12.14. The runner uses
the dev profile. No performance numbers or iPadOS validation are claimed.

## Executed checks

| Suite | Observed result |
| --- | --- |
| cargo fmt / clippy with warnings denied / build | passed |
| cargo test --workspace | 41 unit tests passed |
| M0 differential corpus | 71 QEMU comparisons and 3 fault checks passed |
| M1 differential corpus | 67 QEMU comparisons passed |
| Static BusyBox integration | 18 QEMU comparisons and 1 host-scope check passed |

Total: 156 QEMU comparisons, 4 independent safety checks. Local Cargo checks
also use --locked --offline. The hosted Linux workflow rebuilds the pinned
upstream musl/BusyBox inputs independently; its run result is tracked in the
M1 issue and Actions.

The 64 M1-generated programs each execute 96 new integer operations and emit
X0–X7 plus NZCV. They define initial flags explicitly, because Linux process
entry does not give the differential harness a portable initial NZCV value.
M1 selects QEMU cortex-a53 to match the guest's ARMv8 cache-zero model.
Fixed programs exercise paired/register-offset/signed accesses, SIMD transfers
and immediates, exclusive success and CLREX failure, DC ZVA, and mkdir/chdir plus
file creation, write, seek, read, stat and close. Snapshots compare observable
memory and register data; no filename has special runtime treatment.

BusyBox is cross-built from unchanged BusyBox 1.37.0 and musl 1.2.5 sources.
Initial `echo` tracing required set_tid_address, brk, anonymous mmap, write,
munmap and exit_group. cat/wc/head/tail add read, openat, close, stat and seek;
ls adds newfstatat, directory open flags, fcntl, getdents64, writev and ENOTTY.
The applet test covers nonzero exit, missing files, binary input and directory
iteration. It does not merely install or inspect packages.

Unit boundaries cover failed read preserving file/stdin position, writev
validation before side effects, short writes without retries, brk rejection,
MAP_FIXED accounting, atomic protection changes, descriptor state, VFS node and
storage limits, permissions, pair faults without partial mutations, exclusive
invalidation, and signed divide overflow/zero behavior.

## Remaining gaps

This is a selected static BusyBox foundation, not complete AArch64/Linux ABI
coverage. Full floating point/SIMD, wide BusyBox configurations, symbols/links,
file-backed mmap, signals, blocking futex, process/thread lifecycles, PTYs and
interactive ash remain unsupported. PT_INTERP, musl dynamic linking and Alpine
package execution belong to later work. Apple builds, native SSH, C++ backend
benchmarks, fuzz campaigns and sanitizers have not been completed.
