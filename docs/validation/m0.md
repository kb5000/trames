# M0 validation record

Date: 2026-10-10. Local environment: Debian GNU/Linux 13, x86_64, Rust 1.90.0,
GNU AArch64 Binutils 2.44, QEMU aarch64 user-mode 10.0.13, Python 3.12.14.
The runner was built with the dev profile. No performance figures are claimed.

## Local results

| Check | Observed result |
| --- | --- |
| cargo fmt --all --check | passed |
| cargo clippy --workspace --all-targets --locked -- -D warnings | passed |
| cargo build --workspace --locked | passed |
| cargo test --workspace --locked | 20 passed, 0 failed |
| Python differential suite | 71 QEMU comparisons passed, 3 fault checks passed |

The local Cargo commands also used `--offline`; the workspace has no third-party
Rust dependencies. The suite independently assembles and statically links ELF
fixtures with AArch64 Binutils and runs them in both implementations. The fixed
cases compare stdout, stderr and exit status, including exit 37, NUL/0xff output,
argv, BSS, unaligned cross-page data accesses and negative errno. Sixty-four
generated programs use deterministic seeds 0–63, each exercising 64 arithmetic
and logical shifted instructions after initializing registers. They emit a
72-byte memory snapshot of X0–X7 and NZCV for byte-for-byte comparison.

A renamed Hello ELF with a same-length modified message produces the new bytes
in both runtimes. Thus execution depends on guest contents, not filename.
Fault checks independently confirm a 17-instruction loop limit, an unsupported
instruction, and a store to an RX code page. Unit regressions include ELF prefix
truncation and all 992 single-bit mutations of a valid 124-byte ELF seed, plus
memory range/permission errors, stack layout, register width and syscall errors.
This bounded mutation test is not a coverage-guided fuzz campaign.

## Reproduce

Run the commands in the repository README. Fixture binaries are build outputs,
not committed executable artifacts. The recorded Hello fixture, built with the
tool versions above, has SHA-256:

```text
edee8027537ed3a26def3cf13d04127d6d84e1371ca913c5276856ccc34019fb
```

Different Binutils versions can produce different ELF bytes; the differential
test compares executions of the same locally built bytes, not this fixed hash.

## Remaining validation

The Linux CI workflow is included; its live run is tracked in the M0 GitHub issue
and Actions. A committed workflow alone does not prove a successful hosted run.
C++/QEMU three-way comparisons, sanitizers, broad fuzzing, full AArch64 coverage,
BusyBox, musl, Alpine and iOS cross-compilation/device validation remain future
work. M0 success does not establish those capabilities.
