# M4 validation and remaining acceptance

M4 frontend source and executable validation are in progress. This record does
not establish a signed iPad build or device behavior.

Local Linux evidence:

- 103 Rust workspace tests passed; clippy and iOS embedding target check passed.
- Six Swift tests passed on Swift 6.0.3 Linux: config/pins, SFTP parser and
  real OpenSSH Ed25519 authentication plus a 1 MiB SFTP roundtrip (no PTY).
- The C ABI runs the actual pinned Alpine ash interactively: ANSI color bytes,
  37x103 PTY resize, 1 MiB disk import/export equality, exclusive export,
  pause/resume, cancellation during a busy shell and reopening the same store.
- The pinned rootfs hash rejects a tampered initial installation.
- OpenSSH native transport/SFTP and Apple SDK evidence are recorded after CI.

Required iPad acceptance (not yet run):

- Select a Development Team and install a normally signed app on a physical iPad.
- Cold launch/download and offline reopen the private Alpine shell; verify a
  failed initial install cannot replace an existing store.
- Type/select/copy Unicode and inspect true color with software and hardware
  keyboards; rotate/resize the window and check stty size and foreground SIGWINCH.
- Verify SSH fingerprint against an independent server fingerprint; test unknown,
  changed and known keys, wrong passwords, encrypted Ed25519 and Keychain deletion.
- Exercise SSH PTY/SFTP over IPv4/IPv6, localhost/LAN and Internet; check local
  network consent, Wi-Fi changes, cancellation and network outage errors.
- Import/export 1 MiB and larger files through On My iPad, iCloud Drive and at
  least one third-party provider; test collisions, unavailable providers and
  insufficient storage. Confirm no selected URL remains a live guest mount.
- Background/foreground the app, close a busy local shell, close SSH during
  connection/transfer, and confirm store locks and network sockets are released.
- Inspect memory and energy use with long output and up to eight terminal tabs.

The initial local stack failure from Alpine line editing is covered by the real
embedding integration test. Linux unprivileged OpenSSH cannot allocate a login
PTY in this container; its no-PTY variant verifies native auth/file transfer.
macOS CI runs the PTY variant with the runner's standard local test daemon.
